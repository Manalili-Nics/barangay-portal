# Barangay Mabuhay Community Portal 🏘️

## 📌 Project Overview
A digital portal for Barangay Mabuhay that allows residents to view announcements and request certificates online.

## 🎯 Scenario Chosen
**Scenario B: The Community Resource Hub** - This addresses the need for barangays to digitize announcements and streamline certificate requests.

## 🛠️ Technologies Used
- HTML5 (Semantic)
- CSS3 (Flexbox/Grid)
- Bootstrap 5
- JavaScript (DOM Manipulation)
- Font Awesome Icons

## ✨ Features
- Responsive design (mobile-first)
- Dynamic announcements loaded via JavaScript
- Form validation for certificate requests
- Bootstrap components: Navbar, Cards, Accordion, Modal, Alert
- Live clock showing Philippine time

1. Clone this repository
2. Open index.html in your browser
3. Or use Live Server in VS Code

## 📱 Responsive Breakpoints
- Desktop: > 992px
- Tablet: 768px - 991px
- Mobile: < 768px

## 👨‍💻 JavaScript Function Explained
The `loadAnnouncements()` function demonstrates DOM manipulation by:
1. Selecting the container element
2. Creating new card elements dynamically
3. Appending them to the DOM without page refresh
